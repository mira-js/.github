# Contributing

## Contributor License Agreement

Pull requests to any mira-js repository are merged only after the author has
signed the [Contributor License Agreement (CLA)](https://github.com/mira-js/.github/blob/main/CLA.md).

To sign, open your pull request as usual. The CLA Assistant bot comments on the
pull request with a link to the agreement; follow it and sign with your GitHub
account. You sign once, and the signature covers your later pull requests to
mira-js repositories. The CLA status check on the pull request turns green once
you have signed. Signatures are recorded by
[CLA Assistant](https://cla-assistant.io/).

In short: Contributions require signing the [CLA](https://github.com/mira-js/.github/blob/main/CLA.md) — see [CONTRIBUTING.md](https://github.com/mira-js/.github/blob/main/CONTRIBUTING.md).

The CLA (licence grant) lets the project offer licence exceptions (for example for collector plugins) alongside AGPL-3.0-only.

## Setup and testing

Each repository's `README.md` describes how to install, build and test that
package. Read it before opening a pull request.
